# 테스트용 ATT&CK 번들

`enterprise-attack-mini-<버전>.json` 은 공식 MITRE ATT&CK STIX 2.1 번들(attack-stix-data)에서 일부만 잘라 낸 것이다.
기본 룰·순서도가 참조하는 기법과 그 주변 객체만 남겼고, 구조는 공식 번들과 같다. `scripts/make_attack_fixture.py` 로 다시 만든다.
